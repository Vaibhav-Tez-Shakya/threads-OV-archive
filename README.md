# Threads-OV Archive

This repository stores Claude conversation threads for Threads-OV.

Each Claude conversation is stored as a separate Markdown file inside the 	hreads directory.

## Storage Format

Each thread is stored as:

	hreads/<thread-id>.md

The Markdown file contains the complete conversation, including all user queries and Claude responses.

## Thread Structure

Each thread contains:

- Thread title
- Thread ID
- Creation timestamp
- Last updated timestamp
- Complete conversation history

The same thread ID is used for the entire Claude conversation.
